Resttek API (1.0.0)

Download OpenAPI specification:

API REST del backend de Resttek para la gestión de restaurantes, carta, ingredientes, empleados y pedidos.

Autenticación: los endpoints protegidos requieren una cabecera Authorization: Bearer <token> con el JWT obtenido en /auth/login o /auth/register.

Roles: admin, manager, camarero, cocinero, cliente.

Orders

Pedidos y estado de sus ítems

Crear un pedido

Cualquier usuario autenticado. El clientId se toma del token. Cada ítem con quantity = n se expande en n ítems de cantidad 1 con estado pendiente.

tableId es opcional. Si se envía, debe ser una mesa del restaurante con status = ocupada (si no, 400 TableNotOccupiedError o 404 TableNotFoundError).

Authorizations:
bearerAuth
Request Body schema: application/json
required
restaurantId
required
string <uuid>
tableId
string or null
required
Array of objects
